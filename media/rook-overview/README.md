# Rook — ten-minute customer demo

The [subtitle script](subtitles.srt) and [shot list](video-plan.json) plan a 10-minute video. The video uses customer application footage and Rook’s hosted web UI, with subtitles and no audio.

Locally prepared files are in `delivery/rook-overview/` at the repository root. The application cut is ready for review. The full video still needs the hosted Rook segments; no local Rook viewer is used as a substitute.
